# CCS 105 — Health, Environment, and Society

> University of Embu · Biological Sciences

This pack organizes the available course outline and lecture materials into a
topic-by-topic study path. Search covers the text inside each note. Use the
progress tracker to mark a topic complete only after you can explain it without
looking.

## Learning goals

- Work through each topic in order, or search for a specific term or example.
- Use the interactive recall checklist at the end of each note.
- Record confidence and revision dates in the progress tracker.
- Consult the source material when a note marks a gap or an equation needs checking.
