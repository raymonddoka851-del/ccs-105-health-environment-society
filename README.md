# CCS 105 — Health, Environment, and Society

**[Open the interactive study site](https://raymonddoka851-del.github.io/ccs-105-health-environment-society/)**

This repository contains source-based study notes, an IBM-style progress
tracker, saved topic checklists, active-recall activities, and full-text search.
The notes are organized around the available University of Embu course
materials; topics with unavailable lecture text are identified in the site.

## Build locally

`powershell
powershell -ExecutionPolicy Bypass -File .\docs\_build.ps1
powershell -ExecutionPolicy Bypass -File .\docs\_check.ps1
powershell -ExecutionPolicy Bypass -File .\docs\_serve.ps1
`
